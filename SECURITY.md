# Security

If you find a vulnerability in SpoolWorks or on spoolworks.de, please report it privately through GitHub: **Security → Report a vulnerability** in this repository. Please do not open a public issue.

Helpful to include: what is affected, steps to reproduce, and what an attacker could do. You will get an answer as soon as possible; this is a hobby project run by one person.

Please test only with your own accounts and data, and do not access other users' data or degrade the service.
